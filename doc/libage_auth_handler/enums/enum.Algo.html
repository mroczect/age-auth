Enum Algo

pub enum Algo {
    Sha1,
    Sha256,
    Sha512,
}
Expand description

HMAC algorithm for OTP generation.

§Variants

  • Sha1 – SHA‑1 (160‑bit). Legacy, not recommended for new deployments.
  • Sha256 – SHA‑256 (256‑bit). Default and recommended choice.
  • Sha512 – SHA‑512 (512‑bit). Strongest option, though no practical security benefit over SHA‑256 for OTP.

§Serde

The enum derives Serialize and Deserialize so it can be used in configuration files or API responses.

§Default

The default algorithm is Sha256. You can obtain it via Algo::DEFAULT or DEFAULT_ALGO constant.

§Examples

use libage_auth_handler::Algo;

let algo = Algo::DEFAULT;
assert_eq!(algo, Algo::Sha256);
